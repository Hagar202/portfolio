Nova Sales Assistant

43/44test questions answered correctly, including 14/14 new ones written after the prompt

An AI assistant inside a CRM that briefs sales reps before a call. It answers from 200 CRM leads and a sales playbook with RAG, remembers the conversation so follow-ups like “is their budget enough?” just work, checks every lead against the playbook rules for budget, decision maker and priority, and double-checks every price it writes against the playbook.

  • FastAPI backend, REST API with live docs, web app and 89 automated tests run on every push
